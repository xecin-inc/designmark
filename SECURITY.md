# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.
Report them privately with GitHub's **"Report a vulnerability"** button on the
[Security tab](https://github.com/xecin-inc/designmark/security) of this repository.

We will acknowledge your report within 5 business days and keep you informed until it is resolved.

## Supported versions

Only the latest `1.x` release receives fixes.

## Scope

This repository contains the `designmark` CLI, MCP server and Claude Code plugin. Problems with the website
[designmark.jp](https://designmark.jp/) itself can be reported the same way.

## 日本語

セキュリティの問題は、公開の Issue ではなく、このリポジトリの [Security](https://github.com/xecin-inc/designmark/security) タブの「Report a vulnerability」から非公開でお知らせください。5 営業日以内に受け付けの連絡をします。修正の対象は最新の 1.x だけです。
